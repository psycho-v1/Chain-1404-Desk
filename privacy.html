Privacy

  • No accounts.
  • No application server. Pages are static files.
  • No analytics scripts and no advertising cookies.

localStorage keys

  • desk-theme — light or dark.
  • desk-agreed — ISO timestamp of acceptance.
  • desk-last-review — last Inspect JSON, refused over 5 MB.
  • desk-contract-overrides — addresses you pasted in Monitor.

sessionStorage key desk-current-review holds the live Review object for the Evidence page.

Dropped files never leave the device unless you download the ZIP.

If you put an address in the query string (?address=0x…), it is visible in your URL bar. A static host such as GitHub Pages may keep ordinary HTTPS access logs. This project does not control those logs. Prefer a bookmark you do not share if that bothers you.
