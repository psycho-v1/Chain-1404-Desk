User guide

This guide is for a holder who has a public 0x address and wants to see what two public RPC families currently say. Reading age is about 13. No seed phrase is used anywhere.

1. What 1404 Desk is (and is not)

1404 Desk is a static website. It runs in your browser. It asks public RPC servers for block headers, balances, and a few contract reads. It then shows the answers side by side.

It is not a wallet, not an exchange, not a claim portal, and not a BlockDAG product. It cannot move coins. It cannot pick the “real” chain.

You should now be able to tell a friend that this site only reads public data and never asks for a seed.

2. Why there are two “Chain 1404”s

Think of two suitcases with the same luggage tag. Until a certain day they held the same contents. After 17 February 2026 22:03:01 UTC, public write-ups say the tags still say “1404” but the contents after block 316,002 are not the same.

This site labels the two groups community family and scan family. Those are labels for public endpoints, not a verdict. If the hashes at block 316,002 differ, the page shows DIVERGENT.

Screenshot-as-callout. On Inspect, look at the checkpoint table. Genesis and 316,001 should be compared first. 316,002 is the documented split point.

You should now be able to explain that a chain ID is a label, and two servers can share a label while disagreeing about later blocks.

3. What you need

  • Your public address, starting with 0x and 40 hex characters after that.
  • A browser. A wallet extension is optional.
  • Time to read both columns. Do not stop at the first green number.

You should now be able to start without a seed, a miner serial, or an exchange password.

4. How to find your address in MetaMask / Trust Wallet

MetaMask: open the extension, tap the account name at the top, choose Copy address. You want the 0x string, not a screenshot of a QR code alone.

Trust Wallet: open the wallet, tap Receive or the address under the account name, copy the EVM address.

If the app also shows a “BlockDAG” receive screen, still copy the 0x address. Then use Inspect — do not assume the in-app explorer is showing both histories.

You should now be able to paste an address that starts with 0x into Inspect.

5. How to run Inspect

  1. Open Inspect address.
  2. Paste the address. Add a label if you like (“cold wallet”).
  3. If this pack is for an exchange ticket, fill UID, deposit address, and tx hash. Those fields only feed the letter.
  4. Tap Run live review.
  5. Wait. Some RPCs will fail. Failed rows stay on screen.
The address also lands in the page URL as ?address=0x…. Bookmark that if you want to rerun later. A static host may log the usual HTTPS request, including the query string. See Privacy.

You should now be able to produce two columns of live numbers for one address.

6. How to read the two columns

Left is the community family. Right is the scan family. Each card is one RPC.

  • height — latest block that RPC currently serves.
  • head hash / state root — fingerprints of that tip. Different fingerprints mean different ledgers.
  • balance — native BDAG on that history, plus the raw wei amount.
  • nonce — how many outgoing transactions that history has recorded from the address.
  • blocked / restricted — contract reads, only if the contract address is fully pinned.
  • error — the RPC refused, timed out, or blocked the browser (CORS). That is data too.

You should now be able to compare one field across families without assuming the larger number is “correct”.

7. What the badges mean

Frozen: compliant nodes on that history will not accept that address’s transactions. The key still exists. This is not the same as someone taking the coins.

Restricted: a second list, if the selective contract address is pinned and the method answers. Treat an empty pin as “unknown”, not “safe”.

Divergent: the two RPC families are not showing the same ledger at the documented split block (316,002).

Family split: two RPCs inside the same family disagree with each other. Do not hide that. It means even “one side” is not a single voice.

You should now be able to use those words in an exchange ticket without adding extra drama.

8. How to add a network without sending funds

Open Add networks. Use the wallet button or copy the manual fields. wallet_addEthereumChain only stores metadata. It does not move BDAG.

Because both presets use chain ID 1404, your wallet will usually keep one live 1404 slot. After adding, open wallet settings and check which RPC URL is actually selected before you send anything — and this site will never send anything for you.

You should now be able to add a labelled RPC and then close the wallet without making a transfer.

9. How to build an evidence ZIP for an exchange ticket

  1. Run Inspect. Tap Send to Evidence locker.
  2. Drop screenshots or PDFs. Each file is hashed here. Nothing is uploaded.
  3. Optionally sign the document ID with the same key that owns the address.
  4. Download the ZIP: review.json, files/, two letters, SHA256SUMS.txt.

You should now be able to attach a pack whose hashes you can recompute on any computer.

10. What to send an exchange first

Send the exchange letter first. It is written in a plain “here is the technical output” style (an Art. 71 style request for a clear answer, not a lawsuit). Use the authority letter only if you are actually escalating later.

Both letters say: This is holder-prepared technical output from 1404 Desk. It is not a finding of breach.

You should now be able to attach one letter and the ZIP without claiming the tool found a crime.

11. Safety: fake claim sites, seeds, Discord DMs

  • Anyone who asks for a seed, “sync phrase”, or screenshot of Secret Recovery is not this tool.
  • A site with a “Claim BDAG” or “Unfreeze now” button is not 1404 Desk.
  • Discord and Telegram DMs that rush you to a new URL are a common trap. Open the GitHub source yourself.

You should now be able to close a tab the moment it asks for 12 or 24 words.

12. Limits

This site cannot recover presale cash, cannot prove miner delivery, cannot force a listing, cannot unfreeze an address, and cannot make two ledgers agree.

You should now be able to say what the tool will not do before you spend a day hoping it will.

13. How to verify you are on the real GitHub Pages site

  1. Open the repository named chain1404-desk on GitHub from an account you trust, or from a link you saved yourself.
  2. Use GitHub Pages from that repo (https://<user>.github.io/chain1404-desk/).
  3. Check that the page source loads js/config.js from the same origin, not from a random domain.
  4. Read SECURITY.md. Report clones that add a seed field.

You should now be able to compare the URL bar with the repo name before you paste an address.
